# Class Definitions for US-ATS Dataset

## Overview

| ID | Class | Description |
|----|-------|-------------|
| 0 | Background | Non-pavement areas |
| 1 | Taxiway | Aircraft ground movement paths |
| 2 | Runway | Takeoff and landing strips |
| 3 | Apron | Aircraft parking areas |
| 4 | Taxilane | Paths within apron areas |

---

## Class 0: Background
- Grass and vegetation
- Buildings and terminals
- Water bodies
- Vehicles and parked aircraft
- Any non-pavement area

## Class 1: Taxiway
- Paved paths for aircraft ground movement
- Yellow centerline markings
- Connects runways to terminals/gates
- Typically 50-75 feet wide

## Class 2: Runway
- Main takeoff/landing strips
- White centerline and edge markings
- Runway numbers at ends
- Typically 100-200 feet wide

## Class 3: Apron
- Aircraft parking areas (ramps)
- Large paved areas near terminals
- May contain parked aircraft

## Class 4: Taxilane
- Smaller paths within aprons
- Lead to parking positions
- Narrower than taxiways
